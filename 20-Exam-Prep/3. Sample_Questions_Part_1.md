# Day 20: OCI Foundations - Sample Exam Questions (Part 1)

This session covers sample questions that mimic the style and topics of the official OCI Foundations exam.

### Question 1: Networking - VCN to On-Premises Connectivity
-   **Question:** Which component provides a private connection between a VCN and an on-premises network?
-   **Correct Answer:** Dynamic Routing Gateway (DRG).
-   **Explanation:** The DRG acts as a virtual router for private traffic between your VCN and networks outside the VCN's region, such as your on-premises data center (via VPN or FastConnect). Internet, NAT, and Service Gateways are used for different types of internet or OCI service connectivity.

### Question 2: Networking - Purpose of an NSG
-   **Question:** What is the primary purpose of a Network Security Group (NSG)?
-   **Correct Answer:** To control traffic flow between specific resources within a VCN.
-   **Explanation:** Unlike Security Lists which apply to an entire subnet, NSGs are associated with individual VNICs. This allows for more granular, resource-level firewall rules, which is key for a Zero Trust security posture.

### Question 3: Compute - Instance Template
-   **Question:** What is the term for the combination of an instance's shape, base image, and metadata?
-   **Correct Answer:** Instance Configuration.
-   **Explanation:** An Instance Configuration is a template that is used to launch new compute instances. It is a required component for creating Instance Pools and enabling Autoscaling.

### Question 4: Compute - Purpose of Oracle Functions
-   **Question:** What is the primary purpose of Oracle Cloud Infrastructure Functions?
-   **Correct Answer:** To execute code in response to events or HTTP requests.
-   **Explanation:** Functions is a serverless, event-driven platform. Developers provide code, and OCI manages the entire underlying infrastructure, executing the code only when it's triggered.

### Question 5: Storage - Automating Object Tiering
-   **Question:** What feature of Object Storage enables users to automatically move objects between storage tiers based on predefined rules?
-   **Correct Answer:** Object Lifecycle Management.
-   **Explanation:** Lifecycle Management policies allow you to define rules based on time (e.g., "after 30 days, move this object from Standard to Archive tier") to automate tiering and deletion, helping to manage costs.

### Question 6: Storage - Block Volume Performance Levels
-   **Question:** Which performance level is NOT available in the Block Volume service?
-   **Correct Answer:** Low Performance.
-   **Explanation:** The four official performance tiers are **Lower Cost, Balanced, Higher Performance,** and **Ultra High Performance**. "Low Performance" is not an official tier name.

# Project Itihaas Starter (Expo + Firebase)

## 1) Create Expo app
```bash
npx create-expo-app@latest project-itihaas --template blank
cd project-itihaas
```

## 2) Install Firebase + timeline slider
```bash
npm install firebase @react-native-community/slider
```

## 3) Optional map + 3D starter packages
```bash
npx expo install react-native-maps expo-location expo-gl expo-three three
```

## 4) Run app
```bash
npx expo start
```

## 5) Copy starter files
Use these files from this folder:
- `App.js`
- `src/screens/HomeScreen.js`
- `src/components/TimelineSlider.js`
- `src/data/vijayanagaraData.js`

Then replace your new Expo app files with these equivalents.
